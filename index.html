¿Qué es HTML?

HTML es el lenguaje que crea la estructura de una página web. 
<h1>Hola Daniela</h1>
        <p>Estoy aprendiendo HTML</p>

Hola Daniela

Estoy aprendiendo HTML

¿Qué es DOCTYPE?

Le dice al navegador que el documento está escrito usando HTML5. 
<!DOCTYPE html>
📄 Documento HTML5

¿Qué es CSS?

CSS sirve para cambiar la apariencia de los elementos HTML. 
h1{
   color: hotpink;
}

Hola Daniela

¿Qué es una etiqueta?

Una etiqueta le dice al navegador qué tipo de contenido mostrar. 
<p>Esto es un párrafo</p>
🏷️ <p> → Párrafo

¿Qué es un elemento?

Un elemento está formado por la etiqueta de apertura, el contenido y la etiqueta de cierre. 
<p>Hola</p>
Elemento │ ├─ Etiqueta de apertura <p> ├─ Contenido "Hola" └─ Etiqueta de cierre </p>

¿Qué es un <div>?

Es un contenedor que sirve para agrupar elementos. 
<div>
   Contenido
</div>
📦 Contenedor DIV

¿Qué es la propiedad color?

Cambia el color del texto. 
color: red;

Este texto es rojo

¿Qué es un atributo?

Es información adicional para una etiqueta. 
<img src="gatito.jpg">
Etiqueta: img Atributo: src Valor: gatito.jpg

¿Qué es el <head>?

Guarda información para el navegador.
📄 Página Web │ ├── HEAD │ ├── title │ ├── charset │ └── viewport │ └── BODY

</body>
